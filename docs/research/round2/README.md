canonical changes. They were produced against the round-one Linux source base
643627c, not against the current master. Do not apply them wholesale: some retain
rejected forms or depend on earlier translation-unit layout. Diagnostic or moved
similarity is not fixed-address equality. Every future proposal needs new
semantic evidence, independent review, real frozen compiler/linker execution,

binaries, private proof directories, local loader paths or credentials are
published. The ledger omits private artifact locations and does not pretend the
underlying raw proofs are distributed. Lane-specific audits are not global
verification. No runtime game test, native/Linux raw-object parity, merge, or CI
monitoring is claimed.
